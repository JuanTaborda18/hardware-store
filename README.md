# Hardware Store — Proyecto Final de E-commerce

## Descripción

Hardware Store es un proyecto educativo de comercio electrónico desarrollado con HTML5, CSS3 y JavaScript. Permite visualizar productos tecnológicos obtenidos de una API REST y gestionar un carrito de compras interactivo.

## Tecnologías utilizadas

- HTML5: estructura semántica.
- CSS3: estilos y diseño responsivo.
- Bootstrap 5: componentes visuales.
- Flexbox: distribución de productos.
- CSS Grid: organización de reseñas.
- JavaScript: interactividad y manipulación del DOM.
- Fetch API: consumo de una API REST.
- localStorage: persistencia del carrito.
- Formspree: envío del formulario de contacto.
- GitHub Pages: publicación del sitio.

## Funcionalidades

- Carga dinámica de productos desde Fake Store API.
- Visualización de imágenes, nombres y precios.
- Incorporación de productos al carrito.
- Modificación de cantidades y eliminación de artículos.
- Actualización automática del contador y del total.
- Persistencia del carrito al actualizar o cerrar la página.
- Simulación de compra sin pagos reales.
- Formulario de contacto con validaciones.
- Diseño adaptable a computadoras, tablets y celulares.
- Mejoras básicas de accesibilidad y SEO.

## API utilizada

https://fakestoreapi.com/products/category/electronics

Los productos y precios se utilizan únicamente con fines educativos.

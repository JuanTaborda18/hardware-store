# Hardware Store

Proyecto de preentrega del curso de Desarrollo Web.

## Descripción

Hardware Store es una página web ficticia dedicada a la presentación de componentes para computadoras, incluyendo placas de video, procesadores y memorias RAM.

## Tecnologías utilizadas

- HTML5 para la estructura semántica.
- CSS3 para el diseño visual.
- Flexbox para las tarjetas de productos.
- CSS Grid para las reseñas.
- Media Queries para el diseño responsivo.
- Google Fonts para la tipografía.
- Formspree para el formulario de contacto.

## Funcionalidades

- Navegación interna entre secciones.
- Catálogo de productos.
- Reseñas de clientes ficticias.
- Formulario de contacto.
- Diseño adaptable a dispositivos móviles.

## Objetivo

Aplicar los conocimientos adquiridos hasta la clase 8 del curso de Desarrollo Web mediante la construcción y publicación de un sitio web.
